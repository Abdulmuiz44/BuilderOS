# BuilderOS Roadmap

## Now: MVP foundation

- Local-first Next.js app.
- SQLite runtime store.
- Plugin and capability registries.
- Reference workflows.
- Manual run execution.
- Logs and artifacts.
- Visible permissions.
- Masked local secrets.

## Next

1. Workflow creation and editing UI.
2. Local routine scheduler.
3. Workspace-scoped filesystem permissions.
4. Real repo inspection with safe allowlists.
5. AI-provider capabilities using configured secrets.
6. Encrypted local secrets vault.
7. Docker Compose self-hosting path.
8. Import/export of workflows and plugin manifests.
9. Rich artifact previews.

## Later

- Team/cloud mode.
- Marketplace.
- Distributed workers.
- Browser automation.
- Advanced policy engine.
- Larger knowledge/project graph.
